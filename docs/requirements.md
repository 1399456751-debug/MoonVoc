# MoonVoc 需求文档 v1.0

> 一体化人声处理插件 | 2026-08-03

## 核心定位

- 给**职业混音师**用的一站式人声解决方案
- 主打声音**极致干净透明**
- 染色**可控**：可选无染色或调节染色大小
- 一个插件顶过去一串插件，质量不降反升

## 信号链模块

### 1. 去齿音（双模块，免扫频）
- 模块 A：针对 **3000–5000 Hz**
- 模块 B：针对 **5000 Hz 以上**
- 自动锁定齿音频点，用户只调强度
- 平滑、无失真、零染色
- 好看的旋钮控制强度

### 2. EQ（四段，参考 MÄAG EQ4 但更智能）
| 段 | 类型 | 作用 | 范围 |
|---|---|---|---|
| 1 | 低频搁架提升 | 变厚变暖有力不糊 | 0 ~ +6 dB |
| 2 | 智能凹陷 | 去盒子音/闷感，免扫频 | ±6 dB |
| 3 | 智能提升 | 增加清晰度，免扫频 | 0 ~ +6 dB |
| 4 | 高频搁架（13k / 22k 可选） | 空气感，丝滑无毛刺 | 0 ~ +6 dB |

- 零染色，干净透明

### 3. 压缩（双模式）
- 模式 1：传统中文流行歌
- 模式 2：中文说唱
- 一个大旋钮 + 模式切换
- 透明无染色
- **GR 电平表**（显示压了多少 dB）

### 4. 染色（可选 1~2 种叠加）
- 纯净 / FET / 电子管 / 磁带 / 光电 / 锗管 …（多给几种）
- 每种有强度旋钮

### 5. 棱角 ↔ 圆滑
- 一个旋钮：左 = 圆滑丝滑，右 = 有棱角有劲儿
- （本质是瞬态整形）

### 6. Auto Gain
- 每个模块独立 Auto Gain 开关

### 7. 超采样
- 2x / 4x / 8x / 16x

### 8. 电平表
- 输入 / 输出电平表

### 9. 电平控制
- Headroom 旋钮：±12 dB
- 输入 / 输出音量旋钮：各 ±12 dB

### 10. 混响（双模式）
- 模式 1：流行歌 / 模式 2：说唱
- 绝对干净透明的算法混响
- 一个大旋钮无脑推

### 11. 工作电平指示灯（类上帝粒子）
- 完美运行电平：**闪烁**
- 电平偏低：熄灭
- 电平过高：**爆红灯**

## UI 设计

- 硬件拟物风，**拒绝 AI 风 UI**
- 主题：神秘深邃的 **MoonVoc** 气质
- 面板：暗色高级纹路金属质感（电影外星人遗迹风）+ 光照
- **紫色光效**、粒子效果刻度环，炫酷科技感
- 布局：
  - 左侧：棱角旋钮（上）+ 染色模块（下）
  - 中间：压缩（上）+ EQ（下）
  - 右侧：去齿音 + 混响
  - 其余功能位置合理排布，美观不凌乱
- 右下角个人 LOGO：**TUJZMIXING**（黑暗深邃风）
