# MoonVoc v0.8.0 设计文档

> 2026-09-27 制定。基于用户 8 项需求 + 4 轮澄清（混响命名 / 压缩方向 / UI 性能取舍 / 压缩命名 / 去齿音旋钮）。

## 0. 范围

版本 0.7.0 → **0.8.0**。三项功能改动（压缩重做、去齿音换 DeBess、瞬态增强）+ 五项调整（±18dB、默认英文、两组模式改名、窗口变矮、UI 质感）。

**不改**：EQ 四段智能、染色 6 曲线、超采样 4 档、混响算法本体、参数 ID（`ParamID` 已定死的全部保留原名）。

## 1. 压缩重做（`VoiceComp.h/.cpp` 重写）

### 1.1 为什么要改

用户反馈"一键出来的不好听"。诊断出三个真因（**不是** crest 智能的错，用户明确反对删掉它）：

1. **两级在做同一件事** —— Fast 层阈值 `-30dB × amount`、Smooth 层 `-40dB × amount`，同一个压缩量做两遍，没有分工 → 又糊又扁
2. **没有侧链高通** —— 低频一进来就触发 → "抽气"
3. **没有程序依赖释放** —— 释放时间固定 → 安静段该慢不慢、响段该快不快

### 1.2 新架构：三级串联 + 并行

| 级 | 风格 | 参数 | 职责 |
|---|---|---|---|
| Stage 1 | FET 峰值（1176） | attack 0.3~3ms（crest 驱动）、release 60~120ms、ratio 4~8:1（crest 驱动）、硬拐点 | 只抓字头过冲，削 0~3dB |
| Stage 2 | 光电平滑（LA-2A/CL1B） | attack 15~30ms、release **程序依赖**、ratio 2:1、软拐点 knee 8dB | 做"胶水"，削 0~6dB |
| Stage 3 | 并行密度（New York） | 重压支链（ratio 8:1、attack 0.5ms、深阈值），与主信号混合 0~35% | 增密度不损瞬态 |

信号流：`input → [侧链高通] → Stage1 → Stage2 → (主) ⊕ (重压支链) → output`

### 1.3 保留并强化的智能

- **crest 峰值因子检测保留**，平滑时间常数 1s → **300ms**（响应更快，仍是稳定统计量）
- crest 继续驱动 Stage 1 的 attack / ratio（映射曲线重调，见上表范围）
- **新增程序依赖释放**（Stage 2）：释放系数 = f(当前压缩深度)，压得深 → 释放慢。
  实现：`releaseMs = releaseFast + (releaseSlow - releaseFast) * depthNorm`，
  `releaseFast ≈ 120ms`、`releaseSlow ≈ 1.5s`，`depthNorm` = 平滑后的 GR 归一到 0~1。
- **新增短时瞬态检测**：块峰值 + ~5ms 快 EMA → 瞬态指标，用于 Stage 1 attack 决策（原来只有 1s EMA 一个统计量，太钝）。

### 1.4 侧链高通

二阶高通（RBJ，`Coefficients::makeHighPass`，Q=0.707），截止 **100Hz**，只作用于**检测路径**，不作用于音频路径。

**必须遵守项目既有规则**：检测器系数预分配 `Coeffs::Ptr` + **每块按当前 `dspRate` 重写 raw 数组**（OS 倍率热切换后系数会错位）。

### 1.5 模式（改名）

| 新名 | 中文 | 性格 |
|---|---|---|
| **Glow** | 柔光 | Stage 2 主导，压缩匀、尾巴长（流行唱法）|
| **Forge** | 锻造 | Stage 1 重、并行多、抓得住字头（说唱）|

### 1.6 保留项

- 单旋钮 `compAmount` 0~100% 驱动整链深度
- `compMakeup` 0~12dB 保留
- 30ms 块级参数平滑（防 click）
- GR 表输出（三级 GR 之和）
- 旁通走 10ms 块级 EMA 归零

## 2. 去齿音（新增 `VoiceDeEsser.h/.cpp`，移植 Airwindows DeBess）

### 2.1 来源与授权

Airwindows **DeBess**（2016），MIT 授权。源码已下载到 `reference/airwindows/DeBess*.cpp/.h`。
**源码头部必须保留 `Copyright (c) 2016 airwindows` 版权声明**。

### 2.2 算法原理（与常规去齿音完全不同）

- 维护最近 `sharpness` 个采样的**斜率历史**，再算"斜率的斜率"（二阶差分）
- **连乘结构**：`sense` 由各位置 `|mL[x] - mL[x+1]| × sharpness²` 连乘，只在 `mult < 1.0` 时累乘
  → 任何一处斜率平缓就把 sense 压下去，只有齿音那种高频来回抖动才累积出大值
- 削减：**动态 IIR 内插** `out = iir + (in - iir) / ratio`，ratio 由 sense 平滑得到
- 双 IIR 状态**奇偶采样交替**（`flip`），避免 IIR 采样间耦合

**结果**：方波、锯齿、正常辅音一律不触发，对非齿音内容近乎零染色。

### 2.3 参数映射（双旋钮）

| 旋钮 | 范围 | 映射 |
|---|---|---|
| **Amount** | 0~100% | `intensity = pow(a,5) × (8192/scale)`，`scale = dspRate/44100`（原版 `overallscale` 语义）；`depth = 1/(1 - a×0.9)` |
| **Focus** | 0~100% | 0 = 削低频刺（约 3~5kHz，`iirAmount` 小、`sharpness` 大）；100 = 削高频刺（约 6~10kHz，`iirAmount` 大、`sharpness` 小）；两端之间线性插值 |

原版 5 参数中 `monitoring`（E）不移植（仅调试用）。

**连乘结构的替代**：连乘是 O(sharpness) 每采样。若性能不足，改为「每 4 采样更新一次 sense」（检测窗口尺度远大于 4 采样，听感无损）。

### 2.4 超采样集成（关键）

原版只跑宿主采样率。MoonVoc 模块跑在超采样链内，需换算：

- `scale` 用 **dspRate**（原版语义 = 当前处理采样率），`intensity` 里的 `8192/scale` 自动补偿每采样 slew 变小
- **斜率历史数组按最大 16x 预分配**（`sharpness_max = 41 × 16 = 656` 元素/通道）
- `sharpness` 目标值 **按 OS 倍率放大**，保证检测窗口的**时间长度**与原版在 44.1k 一致
- 遵循项目规则：所有与采样率相关的量每块按当前 `dspRate` 重算

### 2.5 链路位置

`EQ → Comp → **DeEss** → Sat → Edge`（用户指定"压缩模块后"）
在超采样链内运行。GR 表输出削减量。

## 3. 瞬态增强（`VoiceEdge.h/.cpp`）

### 3.1 问题

现算法 `rising = (a - e)/a` 只在起音**瞬间**接近 1，效果极短 → "听不出来"。

### 3.2 新算法：双包络差值

| 包络 | attack | release |
|---|---|---|
| 快 | 0.3ms | 15ms |
| 慢 | 25ms | 250ms |

- `transient = (fastEnv - slowEnv) / (slowEnv + eps)`，clamp 0~1 → 正方向强度
- `sustain = (slowEnv - fastEnv) / (slowEnv + eps)`，clamp 0~1 → 负方向强度
- `gain = 1 + amountPos × kMax × transient - amountNeg × kMax × sustain`
- 效果可持续整个字头，而非一瞬间

### 3.3 深度与代价

- `kMaxBoost` 0.8 → **2.2**（±80% → ±220%）
- 双向：正 = 棱角，负 = 圆滑
- 增益平滑系数 1.5ms 保留（限制变化率降调制失真）
- **预计 THD 从 -77dB 升至约 -60dB** —— 瞬态整形的本分（就是在改波形），非缺陷。**默认（amount=0）必须仍逐样本直通**

## 5. UI

### 5.1 尺寸

- 设计尺寸 **1280 × 720 → 1496 × 672**
- 宽度为横排 6 卡：EQ 320 / Comp 252 / **DeEss 200** / Sat 260 / Edge 172 / Reverb 180，间距 16，边距 16
- 高度削减：去掉底部卡（止于 636）与页脚之间的 64px 空白
  → `16 + 140 + 16 + 320 + 16 + 128 + 16 + 20 = 672`

### 5.2 卡片内部填充（消除"上半部满、下半部空"）

- Compressor / Edge / Reverb 的 hero 旋钮 **120 → 132**，内容垂直分布均衡
- Engine 卡的 Oversampling 下拉改**垂直居中**
- Monitor 卡 3 条 → **4 条**（IN / OUT / COMP / **DE-ESS**），行高/间距微调以适配 128 高

### 5.3 毛玻璃（预渲染缓存）

- `renderBackground()` 额外产出 `bgBlurCache`：背景先 **1/4 降采样** → 高斯模糊（JUCE `ImageConvolutionKernel::createGaussianBlurKernel`，radius 8）→ 放大回原尺寸
- **仅在 `resized()` 重算**（拖旋钮零开销）
- `drawCard` 改为：裁剪圆角矩形 → 贴该区域的 `bgBlurCache` → 叠半透明白（约 0.55）→ 模块色描边 + 顶部高光 + 内阴影

### 5.4 弧环发光

`drawRotarySlider` 的数值弧下方叠 **3 层由宽到窄的光晕描边**（宽 14 / 10 / 7px，alpha 0.05 / 0.10 / 0.18），主弧保持 4px 实色。
鼠标拖动/悬停时发光 alpha **×1.6**。轨道淡环也加一层轻微光晕。

## 7. 验证计划

**headless 回归（必须全绿）**：
- **默认状态全链直通 THD < -92dB**（死守）
- 全链 0 值**逐样本严格直通**（现有断言保持）
- 旁通各模块后 RMS 能量守恒

**新增断言**：
- 压缩：三级各自 GR 独立可测；侧链高通生效（80Hz 强信号下压缩量显著低于 1kHz 同电平）；程序依赖释放（长持续 vs 短脉冲的释放时间差异）
- 去齿音：齿音信号（6~8kHz 抖动）削减量达标；**1kHz 正弦零触发**（染色验证）；`Amount=0` 时透明
- 瞬态：正/负方向的增益变化幅度达 ±220%；THD 记录（不设上限，记录数值）
- 参数：±18dB 边界；默认语言 = 英文
- UI：6 卡坐标 + 间距断言；Monitor 4 条；hero 旋钮 132

**UiSnapshot**：4 状态（中文 / 中文大字 / 英文 / 200%）FAIL=0，并逐张看图确认。

## 8. 风险

| 风险 | 应对 |
|---|---|
| 压缩重写影响面最大 | 分级实现，每级单独断言；旧实现留在 git 历史 |
